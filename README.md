# VK AI Bot

Учебный проект VPi03: AI-бот для сообщества ВКонтакте.

Бот получает входящие сообщения через VK Bots Long Poll API, передаёт текст в AI-модель через OpenAI-совместимый API и отправляет сгенерированный ответ пользователю.

## Возможности

- Получение входящих текстовых сообщений сообщества VK
- Приветствие по команде `/start`
- Генерация ответов через AI API
- Безопасное хранение токенов и ключей в файле `.env`
- Обработка ошибок AI API без остановки бота

## Стек

- Python
- vkbottle
- python-dotenv
- OpenAI Python SDK
- VK Bots Long Poll API

## Установка

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd VPi03
```

Создайте и активируйте виртуальное окружение:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` в корне проекта по примеру `.env.example`:

```env
VK_GROUP_TOKEN=ваш_токен_сообщества_VK
AI_API_KEY=ваш_API_ключ
AI_BASE_URL=[https://api.proxyapi.ru/v1](https://api.proxyapi.ru/v1)
AI_MODEL=gpt-4.1-mini
BOT_SYSTEM_PROMPT=Ты дружелюбный AI-помощник сообщества VK. Отвечай кратко, полезно и по-русски.
```

Не добавляйте `.env` в Git: в нём содержатся секреты.

В настройках сообщества VK необходимо создать ключ доступа сообщества, включить Long Poll API и активировать события входящих сообщений.

## Запуск

```powershell
python bot.py
```

После запуска напишите боту в сообщениях сообщества VK команду:

```text
/start
```

Или отправьте обычный вопрос — бот сформирует ответ с помощью AI.

- Реальные токены и API-ключи хранятся только в `.env`.
- `.env` и `venv/` исключены через `.gitignore`.
- SSL-проверка в приложении не отключается.
